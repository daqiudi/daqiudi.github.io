# 背景音乐使用说明

## 📁 使用方法

1. **准备音乐文件**
   - 将MP3或其他音频格式文件放入此文件夹
   - 建议使用MP3格式（兼容性最好）
   - 文件大小建议 < 10MB

2. **推荐音乐类型**
   - 婚礼进行曲
   - 浪漫钢琴曲
   - 轻柔纯音乐
   - 温馨背景音乐

3. **示例文件名**
   ```
   wedding_march.mp3
   romantic_piano.mp3
   love_story.mp3
   background_music.mp3
   ```

4. **应用会自动检测**
   - 启动时自动扫描此文件夹
   - 在设置面板中可以选择音乐
   - 支持播放/暂停/切换

## 🎵 注意事项

- 确保文件名不含特殊字符
- 使用英文或数字命名最佳
- 音乐时长建议 2-5分钟
- 可以放入多首音乐，应用会循环播放
