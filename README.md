# 3D婚纱照片浏览网页应用

一款基于Three.js的3D炫酷婚纱照片浏览网页应用，提供沉浸式场景体验和丰富的交互功能。

## ✨ 核心功能

### 1. 多风格3D沉浸式场景
- 🏛️ **婚礼教堂** - 神圣庄严的教堂场景，彩色玻璃光效
- 🌸 **花海草坪** - 浪漫的花海草坪，阳光斑驳效果
- 💎 **轻奢室内** - 优雅的室内环境，暖色调聚光灯
- 🌅 **海边落日** - 唯美的海边夕阳，逆光氛围

### 2. 智能照片分组系统
- 按拍摄风格分类（浪漫、优雅）
- 按场景类型分类（室内、户外）
- 按服饰类型分类（白色婚纱、彩色礼服）
- 收藏分组管理

### 3. 3D沉浸式照片墙
- 照片悬浮陈列
- 立体排布展示
- Hover光影放大效果
- 描边高亮动效

### 4. 多模式浏览交互
- **桌面端**：鼠标拖拽旋转、滚轮缩放
- **移动端**：单指滑动、双指缩放、长按预览

### 5. 照片播放模式
- 自动轮播功能
- 4种转场动画（淡入淡出、模糊、闪白、缩放）
- 进度显示
- 播放控制（播放/暂停、上一张/下一张）

### 6. 照片详情交互
- 3D浮窗展示
- 高清放大查看
- 左右翻页切换
- 照片信息展示
- 收藏标记功能

### 7. 场景氛围特效
- 花瓣飘落（教堂场景）
- 漂浮花瓣（花园场景）
- 星光闪烁（室内场景）
- 烟雾柔雾（海边场景）
- 可调节粒子强度

### 8. 3D悬浮导航栏
- 场景一键切换
- 分组快速跳转
- 浏览模式切换
- Hover动效

### 9. 图片上传功能
- 批量上传支持（最多50张）
- 拖拽上传
- 文件校验（格式、大小）
- 上传进度展示
- 自动同步至照片墙

### 10. 主题标题设置
- 自定义新郎新娘姓名
- 编辑副标题
- 调整字体大小
- 选择文字颜色
- 实时预览

### 11. 性能优化
- 图片懒加载
- 分批次预加载
- 可视区域优先渲染
- 移动端自动优化
- 渲染质量可调

### 12. 辅助功能
- 背景音乐开关（预留接口）
- 画面特效强弱调节
- 全屏浏览模式
- 键盘快捷键支持
- 浏览进度提示

## 🚀 快速开始

### 方法一：直接打开
直接在浏览器中打开 `index.html` 文件即可运行。

### 方法二：本地服务器（推荐）
```bash
# 使用Python
python -m http.server 8080

# 或使用Node.js的http-server
npx http-server -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

## 🎮 使用说明

### 基本操作
- **旋转视角**：鼠标左键拖拽 / 单指滑动
- **缩放画面**：鼠标滚轮 / 双指捏合
- **移动视角**：鼠标右键拖拽
- **查看照片**：点击照片
- **关闭浮窗**：点击×按钮或按ESC键

### 键盘快捷键
- `←` / `→`：上一张/下一张照片
- `F`：切换全屏模式
- `Space`：播放/暂停（播放模式下）
- `ESC`：关闭弹窗

### 上传照片
1. 点击右上角上传按钮（📤）
2. 拖拽照片到上传区域或点击选择文件
3. 确认上传

### 收藏照片
1. 点击照片查看详情
2. 点击爱心图标收藏/取消收藏

### 切换场景
点击顶部导航栏的场景按钮（教堂、花园、室内、海边）

### 调整设置
1. 点击右上角设置按钮（⚙️）
2. 修改主题标题、特效强度等
3. 保存设置

## 🔧 开发说明

### 添加新场景
在 `scene-manager.js` 中的 `scenes` 对象添加新场景配置：

```javascript
newScene: {
    name: '新场景名称',
    bgColor: 0x000000,
    ambientColor: 0x404040,
    lightColor: 0xffffff,
    fogColor: 0x000000,
    fogDensity: 0.02
}
```

### 自定义粒子效果
在 `particle-system.js` 中添加新的粒子创建方法：

```javascript
createCustomParticles() {
    // 粒子创建逻辑
}
```

### 修改照片布局
在 `photo-manager.js` 中调整 `wallConfig` 参数：

```javascript
this.wallConfig = {
    radius: 8,      // 照片墙半径
    rows: 3,        // 行数
    spacing: 2.5    // 间距
};
```

## 📝 注意事项

1. 首次加载可能需要下载Three.js库，请保持网络连接
2. 大量照片可能影响性能，建议单次上传不超过50张
3. 移动端会自动降低特效强度以保证流畅度
4. 建议使用现代浏览器以获得最佳体验
